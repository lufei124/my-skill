# AI 短片制作工作流

把「想法 → 成片」做成固定流水线。核心原则：**文字里能挡的错不留到图上；图上能挡的错不留到视频上。** 重画图通常便宜，重生成视频按秒计费。

## 何时启用
用户要做 AI 短片/创意视频、要从想法做到可交付成片、或明确要「导演 + 画师 + 动画师」分工、首尾帧工作流、低抽卡率流程时，加载并按本 skill 执行。不要用它做单张静图或与短片无关的剪辑。

## 角色与工具映射
| 角色 | 职责 | 在本环境 |
| --- | --- | --- |
| 用户 | 选方向、确认画风、批准花钱；看动态、听声音 | 真人确认门 |
| 导演（你） | 故事/分镜/全部提示词、抽帧检查、ffmpeg/Python 后期、调度其他模型 | 本助手 + executor |
| 画师 | 设定图、样帧、每镜首尾帧 | `GenerateImage`；若用户指定 Codex/其他生图工具则按其要求 |
| 动画师 | 首尾帧 → 数秒视频 | `GenerateVideo`；若用户有火山方舟 Seedance（`ARK_API_KEY`）则按其 API |
| 审核（只读） | 另开子 agent，只挑错不改文件；提交生成前必须写「通过」 | `Task` → executor，brief 写明只审 |

开工前问清并记下：**片长、画幅、总预算、要不要配乐/字幕、参考片、偏好画风/配色。** 检查本机能否用生图、生视频、ffmpeg、Python；缺什么直接告诉用户。所有文件放进**新建项目文件夹**，版本只增不删、不覆盖。

**不充值、不代买额度。** 接口欠费就停，先把已有片段粗剪给用户看。你看不到真动态、听不到真声音：没看/没听过的，必须明确说。

## 流水线（必须按序，门禁未过不往下走）

### 1. 故事定稿
用用户的一句话想法完善故事。**优先片段式**（镜间不接戏最稳）；连贯式最易穿帮，除非用户要求。

定稿须满足：
1. 现实逻辑：每个转折追问「为什么 / 东西从哪来 / 够得着吗 / 现实会这样吗」
2. 能用一句话说清主题；说不出就改
3. 开头抓人：最抓眼球画面前置，写清第几秒出现什么
4. 旁人反应像真人：每个包袱写成「问题 → 主角怎么解决 → 旁人反应」；反应有先后，禁止多人同秒同动作
5. AI 拍得出：尽量避开人物交叉、手拿小物件、文字、镜子/倒影、左右不对称特征、一镜换光、一人连做三动作、俯拍看不到脸、配角过多

配歌则转折对副歌、关键动作对重拍。

**门禁：** 用户确认故事前不画任何图。另开审核 agent，**只给定稿故事、不给其他文件与结论**，用下方「故事审核」提示；未「通过」不进入分镜。

### 2. 分镜 + 配色
每个镜头一行：片中时间（配歌按小节）、生成秒数（片中时长向上取整，尽量多留 0.5 秒）、景别、机位、运镜、谁往哪走（画面左右）、表情推进、本镜什么在动、怎么接到下一镜。

有参考片：先逐帧量机位与进出画比例再模仿。无参考片按下列硬性要求：
1. 每镜换角度；全片平视正面最多两次，其余俯/仰/背后/过肩/透过物体
2. 画面始终有运动；多数镜有人/物进画或出画；人不动就让纸片、路人等动；固定机位更要有人从远到近
3. 景别交替：全身/半身/特写，禁止连续多镜同景别
4. 每镜写清「什么在动」（机位、焦点、光、前景飘物、人物小动作至少一样）；该静则静
5. 运镜有理由：跟拍、推近特写、由近拉远
6. 任意一秒截图都好看：头/眼落在画面横向约 38% 或 62%，勿居中

**配色单独定、画第一张图之前定好。** 每场列色表；用代码出每镜 1920×1080 色块草图（标 38%/62%），拼总表给用户确认；再转黑白检查人景分离，分不开就重调配色。

**门禁：** 用户确认分镜与配色前，不画正式镜头。

### 3. 画风与设定图
导演写提示词，画师出图，用户确认风格。再为角色与固定道具出设定图（正/侧与关键表情）。固定物件位置写死（如「纹身在左上臂」）。

**门禁：** 用户确认画风前，不画正式首尾帧。

### 4. 每镜首尾帧
降低抽卡率的关键步。雨、帽子、纹身等易「拍丢」的元素必须画进首帧和尾帧。

画序：
1. 先写清每镜首帧/尾帧/中间发生什么，审核通过再画（省额度）
2. 先画内容最多的一张（常为尾帧），再改出首帧，保证机位与构图一致
3. 同地点同机位在前图上改，不重画整张
4. 若要推近：尾帧 = 裁切放大首帧局部；两图构图完全一样则视频不会推进
5. 提交视频前检查画幅一致（如 16:9），首尾尺寸相同

画完用「首尾帧检查」清单逐条放大核对；只改一小块时，把改好区域贴回原图（整图重绘易漂）。

### 5. 视频提示词 + 提交前审核
固定**七段式**提示词（画风 / 镜头 / 构图与配色 / 人物 / 逐秒 / 声音 / 约束）。逐秒须含：开头 0–0.2 秒完全静止=首帧；结尾 0.3 秒完全停住=尾帧；人物不说话；画面无字/字幕/水印。

写提示词时对照「模型易错表」：同时动作写清先后；风吹统一方向；方向按画面左右；数量写死；少用纯否定句；道具只用首帧已有物；路径写清；每镜只 1–2 个主动作；时间多留一点后期对齐。

**门禁：** 另开审核 agent，材料为提示词文件、首帧、尾帧、设定图、分镜表、配色规则；只输出「通过」或「不通过」+ 改项。通过后报价，**用户同意才提交生成**。

### 6. 生成视频
省钱默认：720p 生成，后期放大到 1080p；新做法先试 1–2 个最难镜头；预算紧优先更便宜档位。声音要听过再用；模型自带音乐若不需要则后期另加。

出问题先问：能否剪掉头/尾坏帧？能否用代码修？修不了才重拍，且只拍这一镜；先改提示词或首尾帧再拍。旧片段保留，新旧一起挑。

### 7. 后期（代码）
转场（盖屏/带过；运动模糊切 8–16 份、半帧快门）、调色（只动彩度/亮度，不动色相；保护强调色与肤色；不加颗粒/柔光/暗角）、色彩空间（按源解码，中间无损，交付 BT.709）、放大（lanczos + 轻锐化，不做整段插帧）、配乐卡点（拍点从原曲测）。抽查切点前后各 3 帧。

### 8. 全片复核与沉淀
另开审核 agent，**只给成片、不给结论**。解码每镜多帧，切点前后各 3 帧；先写看懂的故事与看不懂处；列硬伤/小问题；标明查不了的（动态手感、声音）。写项目总结：画风、提示词、犯过的错，存进项目文件夹。

## 可选：四线程模式
用户要挂机推进或明确说四线程时启用：
- **主做**：你，负责制作
- **审核**：子 agent，只挑错；提交生成前必须「通过」
- **监督**：子 agent，把用户说过的话列成清单，每步查是否遗忘
- **代理**：子 agent，按用户偏好在**事先同意的总预算内**代批提交；超预算停等用户

顺序：做完一步 → 审核 → 监督；分歧交代理；一切决定与花费记入审核记录，用户可随时推翻。欠费即停并粗剪已有片段。

## 可复用提示词模板（填空后发给对应角色）

### 故事完善
```
我想做的片子：[一句话或初稿]。片长：[秒]。
配歌：[歌名、时长、BPM；无则删]。参考片：[有则写，无则删]。
先完善成完整故事，不清楚就问我，确认后再展开。
结构首选片段式；除非我要求，不用连贯式。
展开后须满足：现实逻辑追问；一句话主题；开头抓人并写清秒数；包袱三段写且反应有先后；避开 AI 弱点清单。
配歌则转折对副歌、关键动作对重拍。
```

### 故事审核（新 agent，只给故事）
```
这是一支短片的逐镜头故事。你第一次看，只挑错，不改文件。
1. 按镜头顺序读，先写你看懂的故事。
2. 逐个转折追问：为什么？东西从哪来？够得着吗？现实会这样吗？
3. 能用一句话说清主题吗？
4. 开头抓人吗？最抓眼球画面在前面吗？
5. 旁人反应像真人吗？有先后吗？
6. 哪些镜 AI 易拍错？（人物交叉、手拿小物、文字、镜子倒影、左右不对称、一镜换光、一人三动作、俯拍无脸、配角太多）
每条：镜头、问题、建议改法；没把握写「可能」。最后只写「通过」或「不通过」。
```

### 分镜与配色
```
把定稿故事写成分镜表。每镜一行：片中时间、生成秒数、景别、机位、运镜、谁往哪走（画面左右）、表情推进、什么在动、怎么接下一镜。
有参考片先逐帧量机位与进出画；无则按：每镜换角度（平视正面全片≤2）；画面始终有运动；景别交替；每镜写清运动源；运镜有理由；头/眼在 38% 或 62%。
配色单独设计，画图前定好：[用户喜好或给方案]。每场色表。
用代码为每镜画 1920×1080 色块草图（标 38%/62%），拼总表确认；转黑白检查人景分离。
```

### 首尾帧检查
```
首尾帧画完了，按下面逐条检查，每张放大看。有问题写清哪张、哪里；我同意再改。
材料：[首帧]、[尾帧]、[设定图]、[本镜分镜]
1. 动作要用的道具首帧必须有，否则会凭空出现。
2. 旁人反应提前摆好；一镜到底不能中途切拍别人。
3. 多人不同姿势，避免模型让所有人同动。
4. 给动作留空间（落点、飘向、头顶）。
5. 风向统一。
6. 缩到手机大小看远处人物是否可读。
7. 放大查多余物/怪线。
8. 首尾叠看：不该变的必须一致（墙色、杯大小等），否则视频会渐变漂移。
改图：局部改完贴回原图；额度用完就等，不买额度，不同时堆太多张。
```

### 七段式视频提示词骨架
```
【画风】[一句话]。整段画风、颜色、人物设计与首尾帧完全一致。
【镜头】整段 [X] 秒，[景别]，[机位]，[运镜；不动则写不推不拉不摇、不切镜]。
【构图与配色】[人与物位置，墙与光；对齐首帧]
【人物】[长相、衣服、固定道具写死]
【逐秒】
0–0.2 秒：完全静止，与首帧一模一样。
[每段：谁做什么，表情，手在哪/不能碰什么，朝画面哪边]
最后 0.3 秒：全员停住，与尾帧完全一致。
【声音】只有 [看得见原因的声音]。人物不说话。
【约束】画面里一直只有首帧这些人与物；脸与身形全程不变；一镜到底；无文字/字幕/水印。
```

### 提交前审核（新 agent）
```
你是审核，只读不改。本镜马上提交视频生成，花真钱。
材料：[提示词]、[首帧]、[尾帧]、[设定图]、[分镜表]、[配色规则]。
逐项放大核对：
1. 提示词每句与两图是否对齐（位置、左右、颜色、人数、道具数、衣服、表情）
2. 两图机位、大小、背景是否一致
3. 与设定图、配色、前后镜是否一致
4. 动作是否现实；原因是否写清；手放哪
5. 模型易错点（同动、凭空、长脸、走反、歧义词）
最后只写「通过」或「不通过」；不通过逐条列改项。
```

### 后期
```
用代码做后期：
1. 转场：[哪镜到哪镜，盖屏或带过]。运动模糊切 8–16 份，半帧快门。
2. 调色：按故事分段；只调彩度与亮度，不动色相；保护强调色与肤色；不加颗粒/柔光/暗角。
3. 源 mp4 按正确矩阵解码；中间无损；交付 BT.709。
4. 720p 用 lanczos 放大到 1080p，轻锐化；不做整段插帧。
5. 卡点：拍点只从原曲测。
做完抽查切点前后 3 帧。
```

### 成片复核（新 agent，只给成片）
```
这是成片：[文件]。你第一次看，我不给任何结论。
1. 全部解码；每镜多张全分辨率帧；切点前后各 3 帧。
2. 先写看懂的故事，再列看不懂处。
3. 逐镜查：重复动作、道具数量、穿帮、突跳、颜色跳、脸变形、字的问题。
4. 写明查不了的（动态手感、声音）。
每条：时间、帧号、问题；分「硬伤」和「小问题」。
```

### 四线程启动
```
用四线程做这支片。你当主做，再开三个子 agent，做到成片或欠费为止。
我的要求在：[路径]。总预算：¥[金额]。
主做=制作；审核=只挑错，提交前必须「通过」；监督=列要求清单并盯遗忘；代理=按我的偏好在预算内代批，超预算等我。
顺序：做完→审核→监督；分歧→代理；记录一切决定与花费。不充值；欠费停并粗剪已有片段。
```

## 执行注意
- 每步交付物放项目文件夹，命名含镜号与版本。
- 向用户汇报时用短句说明卡在哪道门禁、要他确认什么（故事/画风/报价/成片），不要倾倒内部提示词全文，除非他要模板。
- 用户指定 Claude Code / Codex / Seedance 等外部工具时，按其密钥与命令接入，仍遵守本流水线门禁；密钥不打印、不写进聊天。

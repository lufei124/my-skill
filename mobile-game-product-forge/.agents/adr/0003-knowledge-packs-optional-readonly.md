# ADR-0003: 知识包可选且只读

- 状态：已采纳
- 日期：2026-07-25
- 影响：知识库边界（难逆）

## 背景

项目知识库（架构、模块、埋点基线、术语、决策等）是人工维护的权威来源。若 AI 可回写，未确认推断会污染权威源；若强制必装，无知识库的项目（模式3）无法运行。

## 决策

知识包可选安装（`knowledge-packs/`，用户在项目初始化时选择）；安装后项目内 `knowledge/` 副本只读消费、人工维护，AI 默认不写入。知识变更只走「知识维护提案」流程（提案写入 `09-knowledge-proposals.md`，人工落库）。

## 备选方案

- **内置必装知识库**：无知识库项目无法运行；通用包混入项目敏感知识。被否。
- **AI 可回写知识库**：未确认推断污染权威源，跨会话不可审计。被否。
- **无知识库概念**：丢失跨 PRD 复用的术语/决策/埋点基线，重复设计埋点。被否。

## 后果

- 项目知识人工维护、AI 只读；AI 提出的知识变更以提案持久化、按状态词追踪，落库由人工回填。
- 无知识库时仍可运行（模式1/2 报告知识缺口，模式3 不读取项目知识）。可变规则见 `references/project-knowledge.md` 与 `skills/game-knowledge-maintenance-proposal/SKILL.md`。

# 移动游戏专项检查

## 目录

1. 设备与交互
2. 生命周期与网络
3. 账号、角色与玩法
4. 资产与奖励
5. 广告
6. IAP 与订阅
7. 时间、活动与配置
8. 版本、灰度与上线

只检查与当前需求直接相关的项目，并把“不适用”理由写入校验报告。

本清单覆盖移动游戏通用的技术与产品风险。目标市场的法定合规（防沉迷/实名认证/版号/隐私等）随市场而异，不在本清单内，须按目标市场单独补检并在评审中作为独立合规面核对。

## 1. 设备与交互

- iPhone 16、393 × 852 仅为原型尺寸，客户端不得写死
- iOS 安全区、灵动岛/刘海、Home Indicator
- Android 状态栏、导航栏和返回键
- 小屏、长屏、不同比例、横竖屏约束
- 长文案、多语言、字体放大、溢出和滚动
- 单手操作、主按钮触达、误触、防重复点击
- 弹窗层级、返回、关闭、取消和系统返回
- Loading/动画期间是否可操作
- 奖励到账、货币/道具变化和反馈优先级
- 弱性能设备、资源加载失败和降级表现

## 2. 生命周期与网络

- 切后台、进程终止、重新进入和状态恢复
- 断线重连、超时、弱网和请求重试
- 服务端成功但客户端未收到结果
- 重复、乱序、延迟回调
- 本地缓存是否过期，刷新和失效策略
- 多设备同时操作和登录状态变化

## 3. 账号、角色与玩法

- 限制按账号、角色、服务器、设备、单局还是活动维度
- 角色切换、服务器切换和游客转正式账号
- 单局内与跨局状态
- 战斗实例唯一标识和恢复边界
- 权限、封禁、未成年、地区或渠道限制
- 老账号、历史数据和迁移

## 4. 资产与奖励

- 扣除与发放的服务端权威性
- 业务幂等键、数据库唯一约束和原子事务
- 并发领取、重复点击、重复回调和补单重跑
- 资产不足、背包满、奖励过期和部分失败
- 邮件补发、补偿、对账、审计和告警
- 退款、撤销和追缴规则
- 客户端动画与真实到账状态不同步时的处理

## 5. 广告

- 广告位、平台、地区、渠道和年龄合规
- 加载、无填充、开始、完整播放、中断、失败和奖励回调
- 客户端回调能否被伪造；服务端奖励验证方式
- 广告请求/奖励凭证的幂等和有效期
- 播放期间切后台、杀进程、网络变化和系统返回
- 次数何时扣减，跨日完成归属
- SDK 不可用、版本兼容和关闭开关
- 展示、点击、开始、完成、验证、发奖和后续结果漏斗

## 6. IAP 与订阅

- Apple/Google 商品、价格和促销信息来自商店
- 商店订单、服务端状态和游戏权益的权威关系
- 购买意图、交易号、原始交易号和权益周期
- 服务端票据/订单验证、通知重试和定时对账
- 待处理、有效、宽限、取消未到期、到期、退款、撤销和未知状态
- 恢复购买、换机、重装、跨设备和账号冲突
- iOS/Android 跨平台权益与订阅管理入口
- 首购、周期和每日奖励的唯一发放范围
- 支付成功但客户端退出/超时后的补单
- 重复订阅、叠加或不叠加规则
- 平台合规、条款、隐私、自动续订文案和客服能力

## 7. 时间、活动与配置

- 服务端 UTC、运营时区、用户绑定时区和业务日定义
- 自然日边界、夏令时、跨时区和改设备时间
- 活动开始/结束瞬间，正在进行流程如何处理
- 配置中途变化、热更新、缓存、失效和错误回退
- 新旧配置兼容、默认值和空值
- 发布、审核、权限、操作日志和回滚

## 8. 版本、灰度与上线

- 客户端最低版本和强制/可选更新
- 新客户端配旧服务端、新服务端配旧客户端
- 灰度人群、平台、渠道、地区和服务器
- 总开关、分层开关和紧急熔断
- 数据迁移、回滚后的数据兼容
- 上线前配置和资源准备
- 核心指标、异常率、重复发奖/扣费和状态不一致告警
- 灰度扩量条件、停止条件、回滚条件和观察周期

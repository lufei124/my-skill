# Document To Interactive HTML v6

## Objective

Transform raw documents into presentation experiences.

Never perform:
Document -> HTML copy

Always perform:

Document
-> Understanding
-> Story Strategy
-> Page Architecture
-> Visual Design
-> Interactive HTML

## Pipeline

1. Analyze document
2. Identify audience and purpose
3. Select narrative framework
4. Plan pages
5. Select visual components
6. Generate HTML
7. Validate quality

## Narrative Framework Selection

Use the most suitable framework.

Pyramid:
Executive decisions and recommendations.

SCQA:
Problems, research, analysis.

Problem Insight Solution:
Product and innovation.

Before After Bridge:
Transformation and improvement.

Story Arc:
Launches and storytelling.

Roadmap:
Planning and execution.

Do not always use the same structure.

## Page Rules

Every page must have:

Level 1:
Main message

Level 2:
Explanation

Level 3:
Evidence

Level 4:
Optional details

Avoid:
- paragraph dumping
- identical card grids
- decorative animations

## Visual Mapping

Choose visuals based on meaning:

Comparison -> Matrix
Timeline -> Timeline
Process -> Flow
Numbers -> KPI/Charts
Architecture -> Diagram
Strategy -> Framework
Research -> Evidence blocks

## Output

Generate:
- HTML project
- presentation specification
- design tokens
- reusable components
- validation report

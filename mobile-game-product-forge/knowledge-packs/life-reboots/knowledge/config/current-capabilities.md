# 当前配置能力

更新时间：2026-07-26

| 配置域 | 状态 | 主要职责 | 新需求复用要求 |
|---|---|---|---|
| 广告全局策略 | 目标架构 | 总开关、总冷却、总频次、保护条件 | 不在业务模块硬编码全局策略 |
| 广告场景 | 目标架构 | 广告类型、地区、频次、冷却、优先级、奖励 | 新广告先登记场景，不直接写死 |
| 商城 Tab 与商品 | 目标架构 | Tab、排序、上下架、地区、平台、货币、SKU、道具 | 商品与场景推送复用同一商品定义 |
| VIP/订阅 | 目标架构 | 权益、订阅、恢复购买、平台商品 | 权益状态以平台与服务端为准 |
| 首页侧边栏 | 目标架构 | 地区、开关、排序、标题、图标、横幅、路由 | 新入口优先配置化 |
| 剧本与标签 | 目标架构 | 剧本展示、标签、创角/局外养成/入局路由 | 新内容优先绑定剧本 ID |
| PV | 目标架构 | 跳过规则和交互字段 | 不再按首次播放硬编码不可跳过 |
| 资源中心 | 迁移中 | 首包资源、语言、总进度和下载流程 | 复用统一总进度与下载确认 |
| NPC 冷配置 | 目标架构 | 模板、人格、关系、事件、资产、模型和 Agent | 经审核发布后运行时只读 |

## 通用原则

1. 配置值由服务端或发布后的只读资源下发，客户端不自行推断权威状态。
2. 地区代码使用明确标准，并区分目标市场、报表筛选地区和实际用户地区。
3. 法币价格、订单、次数、奖励和资产最终以平台或服务端结果为准。
4. 配置表重构优先保留显式字段；不把关键规则隐藏在 JSON 黑盒。
5. 1:1 扩展表可合并；1:N 变体和公共字典保持独立。
6. 每项配置能力应标记“已上线/迁移中/目标架构/规划候选/已废弃”。

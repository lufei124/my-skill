# ADR-0002：AGENTS.md 统一入口，平台文件只链接不复制规则

状态：已采纳

## 背景

项目可能被 Claude Code、Codex、Cursor 等多种 AI 平台编辑，每个平台有各自的入口文件（`CLAUDE.md`、`.cursor/rules/` 等）。若把同一套规则复制到每个平台文件，改一处忘改另一处就会漂移，多平台协作时各 Agent 看到的规则不一致。

## 决策

init 产物里 `AGENTS.md` 是**所有 AI 平台的统一入口**，承载项目规则。平台适配文件（`CLAUDE.md` 等）只做极简指针，链接到 `AGENTS.md`，**不复制规则**。

## 备选方案

- 每个平台文件各写一份完整规则：被否，多份漂移。
- 不生成 `CLAUDE.md`：被否，Claude Code 默认读 `CLAUDE.md`，缺失则体验下降；极简指针成本极低。

## 后果

- 规则只在一处维护，改 `AGENTS.md` 即所有平台生效。
- `CLAUDE.md` 固定为 3 行指针，永不承载业务规则。
- 新平台支持只需新增一个指向 `AGENTS.md` 的指针文件，不改规则正文。
